ポン出し

PonDashi — Mac / Windows

音響現場で、渡された曲を「間違いなく・正しい順で」出すためのポン出しソフトです。曲は1曲ずつ止まり、次の曲が待機します。ネット接続なしで動きます。

新しい版のお知らせ

  
アプリを起動した時にネットにつながっていれば、新しい版があるかを自動で調べます。あれば画面左上に「新しい版 Ver. ○○」が出るので、押してこのページを開き、ダウンロードして入れ替えてください。メニューの「アップデートを確認…」でいつでも確認できます（Ver. 0.9.1 から）。

  
本番中に勝手に画面が出ることはありません。保存してあるイベント・SE・BGM は、入れ替えても消えません。


  
インストールと入れ替え

  

    

      
Mac

      
    
        
  1. ダウンロードした PonDashi-（版）-arm64.dmg を開く
    2. 
        
  2. PonDashi を「アプリケーション」フォルダへドラッグ（新しい版は上書き）
    3. 
        
  3. 初回だけ、アプリを右クリック →「開く」→「開く」
    4. 
      

      
開けない時は「システム設定」→「プライバシーとセキュリティ」の下の「このまま開く」。
「壊れているため開けません」と出る時は、ターミナルで
xattr -cr /Applications/PonDashi.app

    

    

      
Windows

      
    
        
  1. ダウンロードした PonDashi-（版）-win-x64.zip を右クリック →「すべて展開」
    2. 
        
  2. できた PonDashi フォルダを好きな場所へ（新しい版は古いフォルダと入れ替え）
    3. 
        
  3. 中の PonDashi.exe を開く
    4. 
      

      
「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。

    

  

  
Apple・Microsoft の正式な署名がない自作アプリのため、初回に確認が出ます。知り合いの方への配布用です。


  
できること

  

    
1曲ずつ確実にGO はスタンバイ中の1曲だけ。2回押し・連打ガード・残り時間の警告・本番ロック

    
グループとキュー出演者ごとのタブ、きっかけ（音先・板付き・曲フリ・MC）と終了後（停止・続けて・ループ）

    
オートゲイン・オートキュー本編の音量を自動でそろえる（純粋なゲイン）、頭の無音を自動で詰める

    
再生範囲末尾の無音を詰める、途中から再生、MCオケのループ

    
SE・BGMSEパッド8個、客入れ・転換・客出しのBGM（一時停止つき）。BGMだけ別の出力にも

    
ボーカルの被せ調整AIでボーカルを分けて、被せを少し下げる

    
映像出力MP4 の映像を外部モニターへ。何もない時は黒またはロゴ

    
CDから取り込み（Mac）音楽CDを入れてボタンを押すだけ。取り込めた曲からすぐ再生

  


  

    わからないこと・不具合は、渡してくれた人に伝えてください。
